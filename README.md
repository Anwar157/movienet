** Movie Collection App

Movie Collection App is a web application where users can browse movies, download them, and add them to their personal My Collection page. Built with React, Node.js, Express, and MongoDB.

** Features

 1. Display popular movies on the Home Page.  
 2. Browse all movies on the All Movies Page.  
 3. Download movies directly.  
 4. Logged-in users can add movies to My Collection.  
 5. Remove movies from My Collection.  
 6. Data stored in MongoDB.  
 7. Redirects to Signin Page if user is not logged in.  
 8. Responsive and user-friendly UI.

 ** Tech Stack

  Frontend: React, React Router, TailwindCSS / DaisyUI, Swiper  
  Backend: Node.js, Express  
  Database: MongoDB (Atlas)  
  Authentication: Context API (Custom AuthProvider)  
  Notifications: react-hot-toast
